# Контекст для Claude

## Как общаться
- Отвечай **коротко**: без длинных текстов, только главное.
- Пиши по-русски (если пользователь не перешёл на другой язык).
- Пользователь — новичок, учится программировать с нуля. Объясняй просто.

## Проект
- Своя 2D-игра в жанре run-and-gun с боссами, герой — кот Финн.
- Пишем на JavaScript (игра в браузере), по шагам: `game/step1.html`, `game/step2.html`...
- Игра на **английском**. Все тексты для игрока — только в объекте `TEXT`, чтобы потом добавлять другие языки.
- Комментарии в коде пока на русском (для обучения).
- У пользователя Windows.
